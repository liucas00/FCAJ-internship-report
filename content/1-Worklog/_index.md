# WORKLOG

During the internship, the work was carried out over **8 weeks**, progressing from learning AWS fundamentals and developing the Personal Finance Management System to deploying the system infrastructure on AWS, conducting system testing, and completing the required documentation.

**Week 1:** Became familiar with the internship environment and tools including Hugo, Markdown, VS Code, and draw.io; studied AWS fundamentals and practiced AWS Free Tier, IAM, MFA, AWS Management Console, AWS Budgets, and AWS Support. (1.1-week1/)

**Week 2:** Studied and practiced AWS networking with Amazon VPC, Subnet, Route Table, Internet Gateway, NAT Gateway, Security Group, NACL, and VPC Flow Logs; practiced Amazon EC2, CloudWatch, and configured an AWS Site-to-Site VPN connection. (1.2-week2/)

**Week 3:** Studied AWS Lambda and the Serverless model, explored Amazon API Gateway and REST APIs; analyzed requirements, designed the architecture of the Personal Finance Management System, and developed the initial database model. (1.3-week3/)

**Week 4:** Continued studying Amazon DynamoDB, AWS CLI, and AWS Cloud9; refined the system architecture, reviewed the Backend and Frontend, prepared the integration of AWS API Gateway, Lambda, DynamoDB, and IAM, and updated the technical documentation and Portfolio. (1.4-week4/)

**Week 5:** Started deploying the Personal Finance Management System on AWS using Amazon ECS and AWS Fargate, Amazon RDS PostgreSQL, Amazon S3, and Application Load Balancer; performed system testing and optimized Docker Images, ECS Task Definitions, ECS Services, Security Groups, and IAM Roles. (1.5-week5/)

**Week 6:** Deployed the data layer using Amazon RDS PostgreSQL and Redis, managed sensitive information with AWS Secrets Manager, deployed 9 Backend Microservices on Amazon ECS Fargate, and configured Service Connect; also researched Redis Multi-AZ and Auto Scaling for the production environment. (1.6-week6/)

**Week 7:** Completed the traffic distribution layer and supporting services using Application Load Balancer, Amazon S3, CloudFront, AWS WAF, Amazon SES, and Amazon CloudWatch; prepared S3 Receipts/Exports and built the CI/CD pipeline using GitHub Actions, OIDC, and Amazon ECR. (1.7-week7/)

**Week 8:** Conducted end-to-end testing of the entire system and its main functions, reviewed the user interface and security configuration, and evaluated system operation and AWS costs; consolidated issues and completed the architecture diagram, deployment and CI/CD documentation, Hugo Portfolio, demo video, and internship report. (1.8-week8/)
