Trong thời gian thực tập, công việc được triển khai trong **8 tuần**, tập trung từ việc làm quen với AWS, nghiên cứu và phát triển hệ thống Personal Finance Management System đến triển khai hạ tầng trên AWS, kiểm thử và hoàn thiện tài liệu.

[**Tuần 1:**](1.1-week1/) Làm quen với môi trường thực tập, các công cụ Hugo, Markdown, VS Code và draw.io; nghiên cứu kiến thức nền tảng về AWS, thực hành AWS Free Tier, IAM, MFA, AWS Management Console, AWS Budgets và AWS Support. 

[**Tuần 2:**](1.2-week2/) Nghiên cứu và thực hành hạ tầng mạng AWS với Amazon VPC, Subnet, Route Table, Internet Gateway, NAT Gateway, Security Group, NACL và VPC Flow Logs; thực hành Amazon EC2, CloudWatch và thiết lập AWS Site-to-Site VPN. 

[**Tuần 3:**](1.3-week3/) Nghiên cứu AWS Lambda và mô hình Serverless, tìm hiểu Amazon API Gateway và REST API; đồng thời phân tích yêu cầu, thiết kế kiến trúc Personal Finance Management System và xây dựng mô hình cơ sở dữ liệu. 

[**Tuần 4:**](1.4-week4/) Tiếp tục nghiên cứu Amazon DynamoDB, AWS CLI và AWS Cloud9; hoàn thiện kiến trúc hệ thống, rà soát Backend và Frontend, chuẩn bị tích hợp AWS API Gateway, Lambda, DynamoDB và IAM, đồng thời cập nhật tài liệu và Portfolio. 

[**Tuần 5:**](1.5-week5/) Bắt đầu triển khai Personal Finance Management System trên AWS với Amazon ECS và AWS Fargate, Amazon RDS PostgreSQL, Amazon S3 và Application Load Balancer; thực hiện kiểm thử hệ thống, tối ưu Docker Image, ECS Task Definition, ECS Service, Security Group và IAM Role. 

[**Tuần 6:**](1.6-week6/) Triển khai tầng dữ liệu với Amazon RDS PostgreSQL và Redis, quản lý thông tin nhạy cảm bằng AWS Secrets Manager, triển khai 9 Backend Microservices trên Amazon ECS Fargate và thiết lập Service Connect; đồng thời nghiên cứu Redis Multi-AZ và Auto Scaling cho môi trường production. 

[**Tuần 7:**](1.7-week7/) Hoàn thiện lớp phân phối và các dịch vụ hỗ trợ với Application Load Balancer, Amazon S3, CloudFront, AWS WAF, Amazon SES và Amazon CloudWatch; chuẩn bị S3 Receipts/Exports và xây dựng quy trình CI/CD bằng GitHub Actions, OIDC và Amazon ECR. 

[**Tuần 8:**](1.8-week8/) Kiểm thử end-to-end toàn hệ thống và các chức năng chính, rà soát giao diện và bảo mật, đánh giá khả năng vận hành và chi phí AWS; tổng hợp lỗi, hoàn thiện sơ đồ kiến trúc, tài liệu triển khai, CI/CD, Portfolio Hugo, video demo và báo cáo thực tập.
