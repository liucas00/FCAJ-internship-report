# Events Participated

During my internship, I had the opportunity to join several activities related to AWS, Cloud Computing, and Generative AI. These events provided a different learning experience from studying through documentation or tutorials because the topics were presented through competitions, technical discussions, and hands-on activities.

I participated in three main events:

1. **Cloud Architect**
2. **Cloud Architect x Meet Up**
3. **AWS FIRST CLOUD AI JOURNEY - Agent Forge Deep Dive Day 2**

Each event focused on a different area. The first one was mainly a Cloud architecture competition. The second combined the final round of the competition with technical sharing sessions. The third focused on building production-ready Agentic AI systems with Amazon Bedrock AgentCore.

## Cloud Architect Competition

The first event was the **Cloud Architect** competition, where I participated as a member of the team **“Gặp phải thằng liều”**.

The competition focused on AWS knowledge and system architecture. Teams had to answer questions covering different levels of difficulty, from fundamental AWS concepts to more advanced topics such as Enterprise Architecture, Migration, Multi-Account environments, security, and cost optimization.

One of the most useful parts of the competition was having to make decisions within a limited amount of time. Knowing the name or purpose of an AWS service was not enough. We also had to consider why one architecture would be more suitable than another based on performance, security, availability, and cost.

This experience helped me become more comfortable with analyzing technical requirements instead of simply memorizing AWS services.

## Cloud Architect x Meet Up

The second event took place on 11 July 2026. It combined the final round of the Cloud Architect competition with technical sharing sessions.

The final match was between **KLKAT** and **Ngũ Đại Hiệp**. Compared with the earlier rounds, the final questions placed more emphasis on advanced architecture problems.

The final ranking was:

- **1st place:** KLKAT
- **2nd place:** Ngũ Đại Hiệp
- **3rd place:** Young Flame IT

After the competition, the event continued with two technical sessions.

The first session was **“Securing Your Web Apps With AWS Security Agent”**, presented by **Thịnh Nguyễn**, a DevOps, DevSecOps, and Cloud Engineer. The session discussed the use of AI-based security agents to support vulnerability analysis, application protection, and threat response in Cloud environments.

The second session was **“SLA and Monitoring - From SLA to Monitoring what really matters”**, presented by **Nguyễn Huỳnh Sơn**. The presentation explained how SLA can be used as a practical reference for service operation, risk management, and performance measurement.

These sessions helped me connect system design with the operational aspects of a real production environment.

## AWS FCAJ Agent Forge - Deep Dive Day 2

The third event was **AWS FIRST CLOUD AI JOURNEY - Agent Forge Deep Dive**, held on 8 August 2026.

The session focused on building production-ready Agentic AI systems with **Amazon Bedrock AgentCore**.

The theoretical section, presented by **Nghia Tran**, introduced the architecture of AgentCore Memory. The memory system was discussed through two main areas:

- **Short-term Memory (STM):** chat messages and session state.
- **Long-term Memory (LTM):** summaries, user preferences, semantic memory, and episodic memory.

Another important concept was the use of **Namespaces and Metadata**. Namespaces help organize and isolate long-term memory, while metadata can be used to define and filter information within a namespace.

The hands-on section, guided by **Pham**, allowed participants to work directly with an AWS Lab environment. The activities included adding memory to an Agent, using **AgentCore Evaluations** to evaluate performance, and exploring **Observability** features for monitoring Agent execution.

## Overall Takeaways

The three events complemented each other well.

The **Cloud Architect** competition improved my ability to analyze Cloud architecture problems and make decisions under time pressure. The **Cloud Architect x Meet Up** sessions gave me more practical knowledge about security, SLA, and monitoring. The **Agent Forge Deep Dive** expanded my understanding of Agentic AI, especially memory management and observability for AI Agents.

The knowledge gained from these events was also useful when working on the **Cloud Finance Platform**, particularly for AWS architecture, security, system monitoring, and the development of an AI-based financial assistant.
